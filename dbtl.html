DBTL循环

我们采用合成生物学核心的DBTL（Design-Build-Test-Learn）迭代循环，三轮迭代推动项目从概念到验证的快速推进。

第一轮 DBTL · 元件验证
DESIGN

启动子元件筛选

基于文献和数据库，筛选5种响应肿瘤微环境的候选启动子，设计对应RBS和终止子。

BUILD

质粒构建

使用Golden Gate组装法构建6个启动子- GFP报告基因模块质粒。

TEST

荧光强度测定

在模拟肿瘤微环境条件下测试各启动子活性，获得基础表达谱。

LEARN

数据建模

建立启动子活性与肿瘤微环境特征的定量关系模型，指导下一轮设计。

成果：筛选出最优启动子 Promoter-X
第二轮 DBTL · 回路优化
DESIGN

基因回路升级

将最优启动子与microRNA表达cassette组装，构建完整治疗回路。

BUILD

整合质粒构建

使用Gibson组装将多模块整合至表达载体，转化至工程菌株。

TEST

表达效率验证

通过qRT-PCR和荧光检测验证回路表达效率和响应特异性。

LEARN

参数优化

根据表达数据优化RBS强度和启动子组合，提升目标蛋白产量。

成果：表达效率提升10倍
第三轮 DBTL · 体内验证
DESIGN

体内递送策略

设计口服递送方案，优化工程菌的肠道定植能力和肿瘤靶向性。

BUILD

工程菌株制备

构建最终工程菌株，包含完整治疗回路和生物安全遏制系统。

TEST

小鼠模型验证

在MC38结肠癌小鼠模型中评估工程菌的抗肿瘤效果和安全性。

LEARN

数据总结

汇总三轮DBTL数据，形成完整的技术报告和后续优化方向。

成果：肿瘤体积显著抑制，安全性良好
